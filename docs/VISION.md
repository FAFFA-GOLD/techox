# TECHOox（テチョクス）— ビジョンと方針（2026-07-25 記録 / 2026-07-31 改名）

開発者自身が人生の再スタートを切りながら、このアプリを使い・直し・育てていく。  
その実証と発信が主軸であり、販促はその結果としてついてくる。

## チャレンジャーの言葉（忘れない）

> 私とあなたはチャレンジャーです。  
> 負けても失敗してもいい。目いっぱい楽しんでいこう。

開発も人生の再スタートも、完璧より挑戦と楽しさを優先する。

## 届けたい声

> 失敗してもいい。でも失敗と認めて、やり直して、楽しい人生を送ろう。

同じ境遇で再スタートする人、その手前で踏みとどまりたい人、  
そして家計と習慣を整えたい人へ。記録を日常にし、見通しを持ち、少しずつ整える道具を渡す。

## 二層の価値

1. **家計コア（信頼の土台）**  
   給与期の見通し、日々の予算、明細、提出用出力。義務としての家計簿を、続けられる形にする。
2. **習慣・遊び（日常化のエンジン）**  
   生活クエスト、ポイント、相棒の育成、図鑑、部屋など。競争ではなく自分のペース。

## ゲーム／課金の原則（合意）

- **競争なし**: 他人との強さ比べ・ランキングは入れない
- **自己ペース**: だれもが自分の速度で続けられる
- **記録を歪めない**: 支出の水増しで得しない。望ましい行動にポイントを付ける
- **課金は任意の装飾**: 家具・見た目中心。進行に必須にしない。レア確定課金はしない
- **単価感**: 払う人でも月おおよそ 1,000〜2,000 円程度を目安。大多数は無料で十分
- **家具例**: 基本は激安（例: 10円）、期間限定のみ学生でも手が届く水準（例: 100円）

## 発信の位置づけ

- SNS / YouTube は「どう法的に再生し、人生をやり直すか」「そのまでの生活・考え方」が主
- 家計簿をつけることは義務であり、日常化すべき Habit。アプリはその実践道具
- 法的判断は弁護士の助言を優先。発信は一般論と自分の経験に留める
- 売り込むより先に、今日つけた・こう直した・こう考えた、を淡々と見せる

## 製品化の遠景（メモ）

- まず自分用の実用品として完成度を上げる
- 同じ境遇の人へ届ける → 一般の家計ニーズへ広げる
- 課金ユーザーが一定数（例: 300人規模）で独立を視野、は目安の一つ（手数料・税・サーバー費を差し引いて考える）
