## プロダクト要約

- **名前**: TECHOox（テチョクス／旧 Ledger）。個人家計簿 Web。キャッチ「赤字の毒を出す、家計の手帖」
- **技術**: Next.js App Router + TypeScript + Tailwind + Supabase（専用プロジェクト・RLS）
- **ナビ名称（現行）**:
  - 全体家計 `/dashboard`
  - 毎日の支出 `/calendar`
  - 明細 `/transactions`（サブタブ: 一覧 / 項目 / 定期 / カード / ローン）
  - キャッシュフロー `/forecast`
  - 設定 `/settings`
- **二軸の時間**:
  1. **給与期** = 給料日〜次給料日前日（全体家計・キャッシュフロー・カード/ローン）
  2. **カレンダー月** = 毎日の小遣い支出（`/calendar`）
- **ビジョン**: 開発者の再スタート実践道具。競争なしの習慣・遊びは第二層（未実装）
- **貯金システム構想**: **保留**（いじらない）

## 日々支出（カレンダー月）— 仕様詳細

### 用途と予算

| 用途 | 役割 | 予算 |
|------|------|------|
| 家族 | 小遣い枠（旧「デート」） | 〜2026-07: 35,000 固定 / 2026-08〜: DB 編集可 |
| 昼食 | 同上 | 〜07: 15,000 / 08〜: 初期 19,000 |
| 日用 | 同上 | 〜07: 10,000 / 08〜: 初期 10,000 |
| その他 | **個別予算なし**。合計枠から減算 | — |
| 交通費 | **独立予算**。画面「月合計」には含めない | 初期 18,860 |
| Suica | **カード残高**（交通費科目で減算・月合計外）。残高登録が正 | `017_suica_balance_snapshots.sql` |
| 酒・お菓子・雑費 | （CHANGELOG 参照・後から追加） | — |

定数: `src/lib/types.ts` の `POCKET_*` / `resolveCategoryBudget`

**交通費 vs Suica（同じ科目で減らすが別表示）**
- 交通費: 月支給予算 − 使用 → 月末残り＝利益把握
- Suica: 登録残高 − 以降の交通費 → カード実残高の見やすさ（公式アプリが面倒なため）

### UI

- タブ: カレンダー / 用途別一覧
- 月合計は**交通費除外** + 小さめ「交通費 ¥… · Suica ¥…」
- Suica 残高パネル（交通費月予算と並記・残高更新フォーム）
- 休日・昼食一日上限・ポイント決済・メモ・昼食計算ボタン
- アラートバッジ: 注意 / 警戒 / **赤字**（小遣い残高マイナス。赤字は土日も表示）

### 出力

- CSV: Shift_JIS 既定。`?encoding=utf8` で UTF-8 BOM
- PDF: 交通費込み総額＋内訳

## アラート仕様（重要・合意済み）

共通トーン: `ok` / `warn` / `danger`（日々は赤字表示もあり）

### A. 日々ペース（小遣い）

```
gap = remaining - expectedRemaining   // 負 = 目安より使い過ぎ
```

- 目安残高は**日ウェイト進捗**で計算（暦日均等ではない）
  - 通常日ウェイト 1 / **マキコ休み∩会社休日** ウェイト 5（比率のみ。日額1000/5000は使わない）
  - 会社休日＝**土日** または 平日に付けた「休」
  - `src/lib/daily-spend-pace.ts`
- `gap >= 0` → ok  
- `gap >= -max(2000, B * 0.08)` → warn  
- それより悪い → danger  
- バッジは土日・会社休日も表示。休日は**丸枠**で平日と見た目を区別

実装: `daily-spend-pace.ts` ＋ `daily-spend-charts.tsx` / `calendar-client.tsx`

### B. 給与期ペース

貯金目安 **14,000 円 / 給与期**（`DEFAULT_PERIOD_SAVINGS_TARGET`）

## 給与期コア計算

```
各口座の最新実残高（口座ごとの as_of_date）
＋ その口座の翌日〜期末の収支（確定優先、未確定は予定、振替含む）
＝ 各口座の期末予定
→ 合計 ＝ 全体の期末予測残高
```

給料は**次期開始日**に入る。予定→実額確定は定期／カード／ローン共通。

残高更新: 同日支出は残高に含まれ済み扱い（収支のある日は夜更新）。
振替: 出金 −(額+手数料)、入金 +額。手数料既定 0。

## 合意・誤解しやすい点

1. 「その他」は個別予算なし（枠からの減算）
2. 画面の月合計は交通費除外、PDF は交通費込み
3. CSV 既定は Shift_JIS
4. ゲーム機能は VISION のみ・未実装
5. シナリオ切替はライブテーブル全置換。アクティブの payload は空でよい（真実はライブ）
6. ローカルバックアップ復元は**同一ユーザー**のみ（`backup.userId` チェック）。シナリオは同一アカウント内
